# 重构行为约定

基线提交：`cc8d82754d3a7fb2496178e4170b30f373ca8163`。
工作分支：`refactor/behavior-preserving-modernization`。

本轮只调整结构。现有公开类、方法、字段、Lombok 生成的访问器、Mixin 目标、
配置键、默认值和支持版本保持兼容。无仓库调用的公开类不等于可安全删除的内部代码。
发现的功能缺陷单独记录，不夹带修复。

## 调度与扫描

- 模块顺序：GUI、PRINT、FILL、FLUID_REMOVAL、MINE、TRENCH、BEDROCK。
- TRENCH 的 prepareTick 在破坏和动作发送前运行；切换时取消已有工作。
- TakeItOut 等待期间不执行 ModuleManager.tick 的后续逻辑。
- 保持启用切换、缺料周期、队列发送、延迟检测和模块执行的先后关系。
- Module 先检查 tick 间隔，再检查配置，再刷新世界/玩家引用。
- WAITING 位置先重试；保留它与普通候选路径现有的检查差异。
- maxExecs <= 0 表示不限制执行次数；时间限制仍由原定时器协调。
- 原始候选逐个接受超时检查，距离和工作区过滤不能移入无时间预算的循环。
- 一轮仅锁定第一个所需物品；无物品需求不受分类限制；扫描结束清除锁定。
- 保持高亮清理时间、GUI 信息更新时间及提前返回时的状态。

## 范围与放置

- 保持 6 种轴顺序 × 8 种反转组合的精确坐标顺序。
- 保持 floor/ceil/round、世界高度、渲染层轴、玩家上下方选区和移动重建阈值。
- 放置规则按 ClassHook 原顺序匹配；null action 与 skip 标志的组合语义不变。
- 保留 canSurvive、双格植物上半部、水/冰流程及 fallback 顺序。
- 比较动作类型、物品列表、点击面、命中偏移、视角、潜行、等待转向及破坏队列副作用。
- 排队后重新检查工作方块与支撑方块距离；保持预测/数据包路径、潜行恢复和发包顺序。
- 不更换可能改变面遍历顺序的 Map 实现。

## 配置与背包

- OPTIONS 按分类顺序去重；All 按相同分类顺序保留重复；HOTKEYS 来自去重后的 OPTIONS。
- All 仍为原有可重新赋值的公开字段；配置对象身份与初始化顺序保持不变。
- 源槽已在快捷栏时直接成功；否则先检查可拾取槽配置，优先空槽，再询问替换目标。
- 预检查不移动物品、不发包、不显示警告；实际执行保留原提示及创造/生存分支。
- 潜影盒搜索从背包槽 9 开始；精确回塞按内容匹配、旧槽位、同物品备用盒顺序查找。
- 回塞 FIFO、内容多重集合匹配、取料点击顺序、2 tick 延迟关闭及最多 10 次重试保持不变。
- 内容匹配保留 MaLiLib areStacksEqual 语义：1.21.4 基线不比较堆叠数量，但重复条目需逐个匹配。
- 远程交换先应用槽位快照，再更新归还/取出缓存，最后解除 requestPending。
- 保留容器遍历集合类型、5 秒重扫、维度编码版本分支和部分成功语义。

## 不属于本轮

依赖或框架升级、停用旧版本、删除公开 API、修改配置格式/默认值、替换预处理器、
全局状态改依赖注入、调度重写、网络协议改动、放置 TODO 修复。
